Para a realização deste trabalho de Desenvolvimento Web I, eu decidi criar um site estático focado em uma receita fictícia e histórica de como construir e municiar um canhão medieval de ferro fundido. A ideia foi juntar os conteúdos de HTML e CSS que vimos em sala com um tema divertido e diferente. O projeto foi desenvolvido do zero, sem o uso de bibliotecas, frameworks ou código JavaScript, utilizando apenas as duas ferramentas principais exigidas e necessárias para o processo: o VS Codium e o GitHub Pages.
A escolha do VS Codium como editor de código foi puramente prática. Como o meu computador tem configurações mais fracas e trava com facilidade, o VS Codium acabou sendo a melhor opção por ser bem mais leve do que o VS Code tradicional, além de não rodar os serviços de telemetria da Microsoft em segundo plano, o que pesa ainda menos na memória do sistema. Já para a parte de hospedagem e publicação, usei o GitHub Pages.
O processo de desenvolvimento começou na criação da estrutura básica da página dentro do VS Codium. Montei o arquivo index.html organizando as informações da receita histórica através de tags semânticas do HTML5 para estruturar o cabeçalho, os textos, as listas de ingredientes e utensílios, os passos do modo de preparo e uma tabela com os tempos estimados de cada etapa. Na sequência, criei o arquivo style.css para dar uma identidade visual rústica e medieval ao projeto, ajustando as cores de fundo para tons escuros de marrom, mudando as fontes para um estilo serifado elegante e definindo as bordas e o espaçamento da tabela e dos conteúdos centrais.
Depois que o site estava pronto e testado localmente no meu navegador, fiz o upload dos arquivos index.html e style.css criando um repositório público no GitHub. Em seguida, acessei as configurações desse repositório, fui até a aba do GitHub Pages e selecionei a branch principal para fazer a publicação da raiz do projeto. Aguardei alguns instantes até o sistema processar a compilação e gerar o endereço público do site.
Durante todo esse percurso, aprendi bastante sobre como funciona a hospedagem de sites estáticos na prática e entendi a importância de organizar bem os arquivos do projeto para que os caminhos das folhas de estilo funcionem corretamente no servidor. Uma das pequenas dificuldades que tive foi justamente na hora do primeiro carregamento, onde o CSS não puxou de primeira porque eu tinha esquecido de atualizar o arquivo no repositório remoto, mas bastou reenviar o arquivo corrigido e atualizar a página para que tudo rodasse perfeitamente.
